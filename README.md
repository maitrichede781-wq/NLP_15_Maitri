## 1. Objective
The objective of this project is to develop an application based on Natural Language Processing (NLP).

## 2. Introduction
Natural Language Processing (NLP) is a branch of Artificial Intelligence that enables computers to understand and process human language. This project demonstrates the use of NLP concepts through a simple web-based application.

## 3. Problem Statement
To develop a user-friendly application that performs an NLP-based task and provides meaningful results from user input.
